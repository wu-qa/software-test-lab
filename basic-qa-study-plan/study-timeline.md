# 第一大阶段：第1‑12个月（1‑52周）初级夯实到中级测试
 
## 第1‑2月｜第1‑8周：基础加固（MySQL + Linux + 协议 + 测试理论）
 
### 第1‑2周 MySQL
 
- 理论：数据库基础概念，表、字段、主键、索引；select基础语法，where，order by，limit
- 实操：本地安装MySQL，自建业务模拟表（用户表、订单表）；练习基础查询
- 输出：SQL练习脚本 .sql 文件上传GitHub
- 工作联动：工作验证bug优先手写SQL查询，不要依赖页面。
 
### 第3‑4周 MySQL进阶
 
- 学习：group by、聚合函数count/sum；inner/left join多表联查；子查询；简单update insert（谨慎update，练习环境操作）
- 实操：多表关联查询统计订单数据；练习常见查询报错排查
- 输出：多表查询练习SQL笔记，记录踩坑点。
 
### 第5‑6周 Linux基础
 
- 必学命令：cd ls pwd mkdir rm cp mv cat more tail‑f grep ps aux netstat；权限chmod chown
- 实操：虚拟机搭建CentOS7；练习查看日志，过滤错误日志；模拟排查简单报错
- 重点：学会 tail -f 实时看日志 +  grep 过滤错误，工作定位bug高频组合。
- 输出：个人Linux命令速查笔记。
 
### 第7‑8周 HTTP协议 + Fiddler抓包 + 测试理论复盘
 
1. HTTP：请求行、请求头、响应头、状态码200/400/401/403/500；GET POST；Cookie Token Session
2. Fiddler：抓网页、APP接口；看懂请求体响应体；修改请求重放
3. 复盘测试理论：等价类、边界值、场景法；测试计划、用例、缺陷报告、需求评审要点
 
- 输出：抓包截图笔记；整理一份高质量缺陷报告模板。
 
## 第3‑5月｜第9‑20周 Python核心（自动化根基，重中之重）
 
### 第9‑11周 Python基础语法
 
- 内容：变量、数据类型、if判断、for while循环；列表、字典、元组；字符串处理；异常try‑except
- 实操：写小脚本：读取txt，遍历列表，字典数据处理；异常捕获处理报错
- 任务：写脚本批量生成100条模拟用户测试数据保存csv
- 输出：小脚本上传GitHub。
 
### 第12‑14周 函数、模块、文件操作
 
- 学习：函数def、参数、返回值；导入模块；csv/json文件读写；pip安装第三方库
- 实操：封装函数实现读取csv测试数据、写入json结果文件。
 
### 第15‑17周 面向对象基础（不需要吃透高级，够用即可）
 
- 学习：类class、实例、属性、方法、简单继承；构造函数__init__
- 实操：封装一个接口请求工具类，实现get、post方法。
 
### 第18‑20周 Python综合小项目练习
 
- 综合：写脚本，读取csv测试数据，模拟请求，把执行结果输出到json报告。
- Git入门：安装Git；学习add/commit；创建GitHub仓库；把代码提交远程仓库。
 
到此：看得懂自动化代码，能写简单工具脚本。
