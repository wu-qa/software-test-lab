# software-test-lab
> Software QA learning laboratory，软件测试学习实验室

## 📚 项目介绍
本仓库为软件测试学习沉淀项目，持续更新：
- Python + Pytest + Requests 接口自动化测试框架
- 测试学习笔记：Linux、MySQL、HTTP、抓包、测试理论
- 各类练习脚本、小demo
- 接口用例、数据驱动、测试报告示例

## 📂 目录结构
- api_test：接口自动化pytest代码
- notes：学习笔记、面试题整理
- scripts：零散Python小脚本
- docs：测试文档、用例文档

## 🛠 技术栈
Python3 | pytest | requests | Fiddler | MySQL | Linux | Git
